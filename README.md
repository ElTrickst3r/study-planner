# Study Planner

A simple web app for keeping track of study tasks and deadlines.
Built as a prototype for Mandatory Assignment 3 in DAVE3625.

## Status

Under development. The app currently shows a test page.

## Technology

- Python
- Flask
- HTML and CSS

## Run locally

This project uses `uv`. From the project directory:

```bash
uv sync
uv run python app.py
```

Then open the address shown by Flask in the terminal.

## Use of AI

AI is used for brainstorming, planning, code suggestions, and debugging.
Suggestions are tested and reviewed before being included in the app.
